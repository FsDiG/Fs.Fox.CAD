## 核心覆盖与接口边界

Beta 扩展沿用现有模块、平台程序集和基础设施。首次集成的 16 个生产文件在命名重构中将两个公开结果类型分离，当前共有 18 个 Beta 源码文件；原有 143 个共享编译 C# 文件保持不变。新工厂、查询和计算通过独立入口提供，不自动替换稳定 API。编译清单、模块数量及哈希基线反映实际文件，CI 登记对应回归。

完整审查逐行检查了下表全部文件及对应核心／宿主测试，并交叉复核。注释解释算法推导、不变量、数值边界和对象生命周期，不以注释数量代替实现正确性。

## 完整核心审查与修正

2026-10-26 的完整审查以 `979b799` 为起点，修正提交为 `71bfa1d`。此前专项静态评审不是完整审查的替代；修正后的源码、XML 和各能力指南是维护依据。

| 确认的问题 | 修正与回归 |
| --- | --- |
| 直段端点往返计算使 `(0,1)→(1,0.3)` 的下界上移，三角形外点 `(-1,0.3)` 被误判内部 | 直段 AABB 直接使用输入端点；原向／反向、左右外点、顶点边界和内部点回归。圆弧保守范围保持原算法。 |
| 次正规端点的对角距离被舍入到轴向容差，连接错误接受超距间隙 | 阈值谓词对次正规差量和容差共同升尺度，不改变通用长度函数；验证斜距拒绝、轴距接受及普通／次正规勾股边界。 |
| 同类距离舍入使区域外点被当成端点容差内边界 | 点关系端点复用阈值谓词，正反轮廓独立验证 Outside／Boundary。 |
| 清理中单位化后的点积舍入，使 `(0,0)→(1,12)→(-59,17)` 的精确 90° 折点被删除 | 局部转向符号改为最大分量缩放方向，固定参考带算法不变；正反方向保留折点回归。 |
| 次正规参考长度无法可靠归一化，零容差仍可能删除非共线点 | 保守保留次正规非零直段，只清除精确重复点；零容差、开闭状态及反向均有回归。 |
| 范围组合在 `x=y=maximumGap=double.Epsilon` 时误把斜距算进邻近阈值 | 次正规数共同升尺度后计算缩放斜距；保留正常／次正规 `5-12-13` 含边界语义。 |
| 法向量或水平分量约 `1e-200` 时，平方下溢导致有效三角形被当作退化／水平 | 按最大分量缩放求模，维持原容差量纲；两类反例各检查六种顶点排列。 |
| 块交点按容差归一化的平方和会把距离恰为 13 的 `(5,12,0)` 排除在阈值外 | 按最大轴差缩放求斜距，次正规数先升尺度；新增二维／三维含边界公共入口回归，宿主 `Not run`。 |
| 预览眼点和目标各自有限，但相减后的方向可能溢出 | 要求视线方向有限且为正；生产核心新增对应拒绝回归，避免传入无效 GS 相机。 |

另外明确两处契约：网格顶点按目标块表记录的存储坐标追加，普通块定义使用局部坐标；预览只筛选顶层实体，复合实体使用整体范围，不保证输出像素非空白或无内部隐藏几何留白。

## 实际能力限制

- 圆角仅支持全直线且全线同一恒定宽度，不修复整体自交；半径或共享边预算不满足时整体拒绝。
- 点关系的非零绝对 bulge 仅支持 `[1e-8,1e8]`，按偶奇规则查询中心线区域，平面与边界容差分别判断。
- 块求交只处理普通嵌套块的存储曲线；动态块、外参、阵列、旧式多段线和未知曲线拒绝。非均匀变换及重合求交沿用宿主语义。
- 文字测量在 `ZW_2022`、`GC_2022`、`GC_2023` 缺少完整 SDK API 的目标明确抛出 `NotSupportedException`；其他绑定可编译不代表字体实际表现已验收。
- DWG 预览仅提供 AutoCAD 入口；实际渲染、驱动、资源释放和空白像素均不能由核心数值测试证明。
- CAD 命令覆盖样式／工作库恢复、曲线适配、网格归属、连续渲染、异常及删除／恢复，但没有启动 CAD 执行，均为 `Not run`。

实际验收按[宿主 Runner](../tools/HostAcceptance/README.md)和[编译目标与验收宿主](../编译说明.md#编译目标与验收宿主)安排，分别记录产品、完整版本、测试程序集、提交和命令结果。
