## Migration scope

The original `MgdDbg.csproj` declares 132 C# compile items. The maintained
`CADDiagnosticsShared` tree retains the same 132 relative source paths;
`App/AssemblyInfo.cs` is preserved for provenance but excluded from SDK-style
compilation because assembly metadata is generated by the two host projects.

The migration also embeds the WinForms resources, legacy icons and the 19-file
`ReportBrowser` directory. Historical documentation and example report files
that are not runtime inputs remain only in the preserved third-party snapshot.

Intentional derivative changes include:

- namespace migration to `Fs.Fox.CAD.Diagnostics`;
- SDK-style AutoCAD 2019 and AutoCAD 2025 host projects;
- explicit adapters for API differences and removed .NET APIs;
- deterministic, idempotent removal of registered events and menus;
- embedded report resource extraction after a successful DWG statistics run;
- the added `MgdDbgAbout` command;
- internal visibility for helper types that are not AutoCAD entry points.

Original `MgdDbg...` command names, English UI labels and test entry ordering are
preserved. The archived snapshot is not built and must not be modified as the
maintained implementation.
